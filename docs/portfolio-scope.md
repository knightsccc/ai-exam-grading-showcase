# Public Portfolio Boundary

This repository demonstrates product thinking, system architecture, and
engineering practices without publishing the private implementation.

## Included

- A synthetic interactive workflow
- High-level system architecture
- A generic Python evaluation contract
- A small standard-library test suite
- Privacy and human-review design principles

## Excluded

- Source files from the private thesis repository
- Git history from the private thesis repository
- Real student or teacher information
- Exam images, OCR output, grades, and review notes
- Production prompts, rules, thresholds, and model routing logic
- Benchmark samples, labels, reports, and experiment artifacts
- Hostnames, API keys, model paths, and deployment scripts

## Sharing Policy

The complete implementation remains private while the graduate thesis is in
progress. A limited code review can be arranged for a verified reviewer using
a separately prepared, access-controlled snapshot.
